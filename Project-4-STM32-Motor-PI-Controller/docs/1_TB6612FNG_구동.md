1. 목표
TB6612FNG 배선 + PWM 기초 구동 (정방향/역방향/속도 조절)

2. 학습 내용
- H-Bridge 원리, TB6612FNG 진리표(IN1/IN2/PWM/STBY) 확인
- 모터(GA12-N20) 6가닥 배선 구조: 모터 구동 2가닥(M1/M2) + 엔코더 4가닥(VCC/GND/C1/C2) 분리
- Arduino 핀 이름(A2, A3, D3)과 실제 STM32 핀(PA4, PB0, PB3) 대응표 확인
- CubeMX 핀 모드 설정: GPIO_Output(AIN1/AIN2), TIM2_CH1(PWMA)
- H-Bridge 진리표 기반 방향제어 코드 작성(HAL_GPIO_WritePin, __HAL_TIM_SET_COMPARE)

3. 시행착오
- Arduino 핀 이름(D3)과 실제 STM32 핀(PB3)을 착각해서 AIN2를 잘못 배선할 뻔함 
  ->Nucleo 핀맵 표 대조 후 A3(PB0)로 정정
- 초기 듀티비(699, 약 70%)로 설정하니 모터가 너무 강하게 회전 
  -> 300(약 30%)으로 낮춰 안전하게 테스트

4. 배운 것
- TB6612FNG 진리표(IN1/IN2/PWM/STBY)를 직접 확인하여 정방향/역방향 시의 
  H/L 값을 코드로 작성 레지스터(CCR) 설정으로 방향 제어와 
  듀티비 기반 속도 조절을 동시에 구현하는 원리
