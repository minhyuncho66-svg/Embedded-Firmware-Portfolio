학습 내용
- HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_13)으로 버튼(PC13) 상태를 읽는 코드 작성
- 활성저(Active Low) 개념 학습: 버튼을 누르면 오히려 0(GPIO_PIN_RESET)이 들어옴
- if-else 구조로 버튼이 눌렸을 때는 __HAL_TIM_SET_COMPARE로 밝기 999(최대), 
  안 눌렸을 때는 0(꺼짐)으로 설정하는 로직 완성
- 실제 보드에서 버튼을 누르면 LED가 밝아지고 떼면 꺼지는 것을 확인

학습 중 생긴 의문
- 코드에 계속 사용한 GPIOC, GPIO_PIN_13이라는 이름이 
  정확히 어디서 나온 건지, 왜 이런 이름으로 되어있는지 이해가 안 됨

답변
- main.h 파일을 열고 GPIO_PIN_13을 검색해보니 #define B1_Pin GPIO_PIN_13
  #define B1_GPIO_Port GPIOC라는 매크로 정의를 발견함
- B1은 Nucleo 보드에 실제로 있는 파란 버튼의 이름이고, CubeMX에서 핀을 설정하면 
  이렇게 자동으로 읽기 쉬운 별명(매크로)을 만들어준다는 것을 이해함
- 즉 GPIOC, GPIO_PIN_13은 우리가 임의로 만든 게 아니라 CubeMX 설정이 코드로 변환된 
  결과물이라는 것을 확인함
