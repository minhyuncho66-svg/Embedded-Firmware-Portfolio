학습 내용
- STM32CubeIDE 설치 및 새 프로젝트(LED_Test) 생성
- STM32F411RE 칩을 검색해서 선택
- CubeMX 핀맵 화면에서 PA5를 GPIO_Output(LED)으로 설정
- PC13은 Nucleo 보드 기본값으로 이미 
  B1(파란 버튼)에 자동 연결되어 있음을 확인
- 보드를 USB로 연결하고 장치관리자에서 
  ST-Link Virtual COM Port(COM3) 인식 확인
- Build 실행(0 errors, 0 warnings) 후 
  실제 칩에 첫 다운로드(Flash) 성공

학습 중 생긴 의문
- 우리가 직접 짜는 코드랑 CubeMX가 자동으로 
  만들어주는 코드는 정확히 어떻게 나뉘는 건가?

답변
- CubeMX는 클럭 설정(SystemClock_Config), 
  핀 초기화(MX_GPIO_Init) 같이 매번 반복되고 실수하기 쉬운 환경설정 코드를 자동으로 생성해줌
- 우리는 while(1) 무한루프 "안쪽"의 실제 동작 로직만 직접 작성하면 됨
- 즉 "집의 뼈대(기둥, 배선)"는 자동으로 세워지고, "그 안에서 실제로 어떻게 동작하게 만들지"는 
  전부 직접 설계해야 하는 구조라는 걸 이해
