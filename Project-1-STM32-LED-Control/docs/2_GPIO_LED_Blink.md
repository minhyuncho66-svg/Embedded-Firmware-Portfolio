학습 내용
- HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET/RESET)와 HAL_Delay(500)를 사용해 
  0.5초 간격으로 LED가 깜빡이는 코드를 "켜기→대기→끄기→대기" 순서로 직접 설계
- HAL_GPIO_WritePin() 함수 내부 코드를 직접 열어서 실제 구현부 확인
- 실제 보드에 업로드하여 LED가 물리적으로 깜빡이는 것을 처음 확인함

학습 중 생긴 의문
- HAL_GPIO_WritePin() 내부에 
  GPIOx->BSRR = GPIO_Pin; 같은 코드가 있었는데, 
  이게 2주차에 배운 내용과 관련이 있는 건가?

답변
- GPIOx는 GPIO_TypeDef라는 구조체를 가리키는 포인터이고, 화살표(->)로 멤버(BSRR)에 접근하는 방식은 
  사전에 학습한 구조체 포인터 문법과 완전히 동일했음
- 즉 HAL 라이브러리 함수 내부는 사전에 연습했던 "실제 하드웨어 메모리 주소를 구조체로 캐스팅해서 다루는" 
  원리를 그대로 사용하고 있었음
- 2주차에서는 "완벽 이해보다 패턴 노출"이 목표였는데, 오늘 실제 HAL 코드에서 그 패턴을 다시 만나면서 
  이해가 훨씬 확실해짐
