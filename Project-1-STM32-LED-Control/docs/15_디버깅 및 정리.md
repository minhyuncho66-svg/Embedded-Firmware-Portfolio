학습 내용
- 디버그 모드로 프로그램을 실행하고 108번 줄(__HAL_TIM_SET_COMPARE)에 브레이크포인트 설정
- Window > Show View로 SFR(레지스터) 뷰어를 열어서 TIM2 > CCR1 레지스터를 실시간으로 관찰
- 버튼을 누른 상태에서 F6(Step Over)으로 한 줄씩 실행하며 CCR1 값의 변화를 확인
- README.md, summary.md를 작성하고 GitHub에 프로젝트 최종 업로드

학습 중 생긴 의문
- 코드에서 999라고 설정한 값이 진짜로 칩 내부의 물리적 레지스터에 
  그대로 들어가는 게 맞는지 눈으로 확인하고자함

답변
- SFR 뷰어에서 CCR1(주소: 0x40000034)의 값을 16진수 0x3e7로 직접 확인함
- 0x3e7을 10진수로 계산해보면 3×16²+14×16¹+7×16⁰ = 768+224+7 = 999로, 
  코드에서 설정한 값과 정확히 일치함
- 즉 코드에서 설정한 밝기값이 실제 칩의 물리적 메모리 주소에 
  그대로 반영된다는 것을 숫자로 증명함
