#7: 공용체/ 비트필드

### 오늘 배운 것
- 구조체와 구조가 같은 공용체 선언 시 안에 있는 모든 멤버들의 주소가 같으므로 값을 다른
  타입으로 재해석 할 수 있게 해줌
- 비트 필드안에 있는 비트 수만큼 읽어내어 값 출력하여 넘치는 값이 잘림


### 예측 vs 실제
- 공용체 안에서의 주소가 같아 세 변수의 주소를 출력시 모두 같을것으로 예측 및 실제 확인
- 변수안에서의 주소가 같으므로 변수들을 다른 타입으로도 출력 가능
- 비트 필드로 비트 초과시 비트 수 만큼 읽어내어 값을 출력하여 할당한 비트 수만큼 출력 한다는걸 
 예측 및  확인
