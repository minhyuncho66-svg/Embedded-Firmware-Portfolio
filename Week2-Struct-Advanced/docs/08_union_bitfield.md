## Day 8: union + bitfield 융합 (레지스터 패턴)

### 오늘 배운 것
- GPIOx_MODER 레지스터는 핀 1개당 2비트씩, 16개 핀으로 32비트를 구성
- union으로 "32비트 통짜(all)"와 "16개로 쪼갠 비트필드(bit)"를 묶으면
  같은 메모리를 다르게 접근 가능
  (Day 7의 union 원리가 실제 레지스터 제어에 쓰이는 걸 확인함)
- all = 0으로 초기화하면 32비트 전체를 한 번에 0으로 설정 가능
  (bit로 하나씩 초기화 안 해도 됨)

### 오늘 가장 어려웠던 질문과 스스로 찾은 답
- "all이 왜 필요한가, bit만 쓰면 안 되나?" 
  → all과 bit는 union이라 같은 메모리를 공유하기 때문에
    all=0 한 줄로 32비트 전체를 초기화할 수 있다는 걸 이해함
- "2비트가 왜 3이 되는지" 
  → 2진수 11을 1×2¹+1×2⁰ = 3으로 계산하는 원리를 다시 확인함
