#6: 중첩 구조체 (BMS Pack 계층 구조)

### 오늘 배운 것
- 구조체안에 다른 구조체를 넣은 후 그 구조체의 배열을 넣으면 포함관계를 표현할 수 있음
- 이를 이용할시 항상 작은 단위부터 만들어서 위로 쌓아 올려야됨
- 구조체안에 구조체로 접근할때는 "."(점)과 '[]"(대괄호)를 이어 붙이면됨
- 함수 인자로 여려개의 인덱스르르 받으면 어디를 바꿀지 함수를 부르는쪽(main)에서 자유롭게 정할 수 있음
- 포인터인곳은 ->로 배열안의 진짜 구조체는 .으로 접근

### 예측 vs 실제
- 점을 여러 번 이어서 접근 가능할 거라 예측 → 실제로 가능했음
- Pack 전체 sizeof가 각 단계 합과 같을지 예측 → Cell(4바이트) × 16개 = 64바이트로 정확히 일치함
  (패딩 없이 딱 맞아떨어진 이유는 다음에 더 알아볼 것)

### 오늘 겪은 시행착오
- 구조체 변수(myPack)를 초기화 안 하고 바로 써서 
  -13108 같은 쓰레기값이 출력됐음
  → "초기화 안 하면 쓰레기값" 문제가 
    구조체에서도 똑같이 적용된다는 걸 다시 확인함
  → struct BMS_Pack myPack = {0}; 으로 고쳐서 해결
- 함수 인자가 왜 필요한지 처음엔 헷갈렸음
  (사용자 입력을 받는 건지, 코드에서 직접 값을 넣는 건지 혼동)
  → #2의 swap_correct(&a, &b) 호출 방식과 같은 원리라는 걸 
    이해하고 나서 헷갈림이 풀림
