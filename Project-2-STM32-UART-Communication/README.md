# Project-2: STM32 UART Communication

## 개요
STM32 Nucleo-F411RE로 UART 통신, 인터럽트 기반 수신, 링버퍼, 명령어 파싱을 구현한 프로젝트

## 구현 과정 (단계별)

### 1단계 (16): UART 기초 송신 HAL_UART_Transmit()으로 1초마다 "Hello STM32!" 송신

### 2단계 (17): 데이터 포맷팅 sprintf()로 가상 BMS 센서 데이터 (온도, 전압)를 포맷팅해서 송신

### 3단계 (18): RX 인터럽트 + 링버퍼 HAL_UART_Receive_IT()와 콜백 함수로 1바이트씩 수신, 링버퍼에 
저장, Echo 기능 구현

### 4단계 (19, 최종): 명령어 파싱링버퍼 데이터를 선형버퍼로 조립, strcmp()로 "LED_ON"/"LED_OFF" 
명령어 인식, 실제 LED 원격 제어 성공

**최종 코드는 main.c에서 확인 가능합니다.**

## 3주차와의 연결
- 3주차에서 만든 LED 제어 로직(HAL_GPIO_WritePin)을 4주차 UART 명령어 처리에 재활용

## 시행착오
- NVIC 인터럽트 설정을 안 해서 콜백 함수가 
  호출 안 되는 문제 → 브레이크포인트로 원인 좁히고 CubeMX NVIC Settings에서 해결
- 링버퍼 인덱스 중복 증가, =/== 혼동 등 여러 실수를 스스로 발견하고 수정

- 링버퍼(원형)와 선형버퍼의 역할 차이
