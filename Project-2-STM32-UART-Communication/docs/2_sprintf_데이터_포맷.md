학습 내용
- sprintf() 함수의 사용법 및 구현 원리
- 숫자는 컴퓨터 메모리에 이진수로 저장되어 있어서, UART로 그대로 송신하면 사람이 알아볼 수 없음 
  → 아스키 코드(문자)로 변환해서 보내야 함
- sprintf(배열, 형식지정자, 변수1, 변수2...)로 구현하여, 배열 안에 변수들을 하나의 문자열로 변환해서 송신
- 숫자가 음수일 때도 %d 정수 형식지정자가 부호(-)까지 알아서 변환해줌
- sizeof가 아닌 strlen을 사용하는 이유: sizeof는 미리 지정해둔 배열이 있을 시 그 "전체 크기"를 계산하지만, 
  sprintf()는 실행 중에 동적으로 실제 글자 수가 변하기 때문에 strlen으로 실제 채워진 길이만 계산해서 송신해야 함
- 가상 BMS 센서 데이터(온도, 전압)를 sprintf로 포맷팅해서 1초마다 UART로 전송하는 코드 완성

학습 중 생긴 의문
- 왜 온도는 int16_t, 전압은 uint32_t로 서로 다른 타입을 쓰는지 헷갈림
- 3700이라는 값이 왜 굳이 32비트 타입이어야 하는지 의문

답변
- 타입 선택 기준은 크게 2가지:
  1) 부호 필요 여부(음수 가능성)
  2) 저장해야 할 값의 최대 범위

- 온도(int16_t): 영하가 될 수 있어 "부호 있는" 타입이 필요하고, 온도 범위는 보통 -32768~32767(16비트)면 
  충분히 커버 가능해서 메모리 절약 차원에서 16비트 선택

- 전압(uint32_t): 전압은 0V 이상이라 "부호 없는" 타입이면 충분하지만 BMS에서는 전압을 mV 단위로 다루는 경우가  
  많아 배터리팩 전체 전압이 수십만 mV까지 커질 수 있음
  → 16비트(최대 65535)로는 부족할 수 있어 32비트로 넉넉하게 잡는 게 실무 관례
- 지금 코드의 3700 자체는 16비트로도 충분한 크기지만 더 큰 값이 들어올 가능성을 대비해 32비트를 선택한다는 
  것을 이해함
