19_명령어 파싱

학습 내용
- 지금까지는 받은 글자를 그대로 다시 보내는 echo 방식만 사용했는데 오늘은 받은 글자를 모아 "LED_ON"이라 
  는 완전한 명령어로 인식해서 그에 맞는 동작을 시키기 위한 파싱 방식을 학습
- "LED_ON"이라는 명령어가 들어왔는지 확인하기 위해 strcmp() 함수 사용
- 링버퍼 안에 순환중인 배열은 strcmp() 함수에서 바로 사용이 불가능함 → 선형버퍼(임시배열, cmd_buf)를 
  만들어서 그 안에 pop한 글자를 한 글자씩 넣고, 엔터(\n)가 오면 "명령어 끝"으로 판단하는 로직 생성
- "LED_ON"이라는 문자열과 strcmp()로 비교하기 위해 선형버퍼 끝에 \0을 자동으로 추가하여 비교하고 
  일치하면 실제 동작(HAL_GPIO_WritePin으로 LED 제어) 실행 아니면 계속 글자를 쌓는 로직으로 완성

학습 중 생긴 의문 1
- cmd_buf[cmd_idx++] = received; 코드를 쓰고 나서 그 다음 줄에 또 cmd_idx++;를 추가해서 
  인덱스가 한 글자당 2씩 증가하는 실수를 함

답변 1
- cmd_buf[cmd_idx++] 자체에 이미 "사용 후 1 증가"라는 의미가 포함되어 있어 
  뒤에 cmd_idx++를 또 쓰면 중복으로 증가한다는 것을 다시 확인하고 하나만 남겨서 해결함

오늘의 최종 성과
- Putty에서 "LED_ON" 입력 → strcmp 비교 성공(MATCH! 확인) 
  → 실제 STM32 보드의 LED가 켜지는 것까지 성공
- PC에서 명령어를 입력해 실제 하드웨어를 원격으로 제어하는 완전한 양방향 통신 시스템을 완성
