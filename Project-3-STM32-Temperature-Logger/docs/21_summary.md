■ I2C 이론
- I2C(Inter-Integrated Circuit)는 UART와 달리 SDA(데이터), SCL(클럭) 단 2개의 선으로 
  여러 장치를 동시에 연결 가능한 통신방식
- 동기(Synchronous) 통신: SCL이 클럭 신호를 같이 제공하기 때문에 UART(비동기)보다 
  타이밍 문제가 적음
- 마스터(STM32)가 슬레이브(센서, OLED)를 7비트 고유주소로 호출하는 구조 
  (BMP280: 0x76/0x77, OLED: 0x3C)

■ BMP280 이론
- 반도체 칩마다 미세하게 달라서 공장에서 칩마다 고유 보정계수를 저장해둠
- 레지스터 맵(0xFA~0xFC: 원시온도 0x88~0x9F: 보정계수)에서 데이터를 읽어와 
  검증된 보정공식에 넣어 정확한 온도 계산
- 보정공식은 제조사가 실험적으로 만든 것이라 "왜 16384로 나누는지" 등은 이해보다 
  "가져다 쓰는" 방식으로 접근

■ CubeMX 설정 + 실전
- I2C1 활성화, PB6(SCL)/PB7(SDA), Fast Mode 400kHz 설정
- HAL_I2C_IsDeviceReady(&hi2c1, 주소, 시도횟수, 타임아웃)로 장치 스캔
- HAL_StatusTypeDef 반환값(HAL_OK)으로 성공/실패 판단
