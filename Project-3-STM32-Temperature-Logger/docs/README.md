Project-3-STM32-Temperature-Logger

STM32 Nucleo-F411RE로 I2C 통신, BMP 280 온도 센서 데이터 수집, OLED 실시간 출력, UART 송신을 구현한 
프로젝트

1단계 (21): I2C 기초 - CubeMX 설정, BMP280 주소값 확인
2단계 (22): BMP280 온도 읽기 - BMP280 내장 온도 측정 센서의 raw값을 보정계수 공식을 이용 / 보정값으로 출력
3단계 (23): OLED 디스플레이 - Nucleo 보드와 OLED 배선 연결 및 기본 함수 구현으로 글자 출력
4단계 (Day24, 최종): 통합 - 온도센서를 통해 읽어온 온도 보정값을 OLED 디스플레이와 
         UART로 동시 출력, I2C 멀티 슬레이브 버스 공유 구조 검증

시행착오
- CTRL_MEAS 레지스터 값 계산 시 비트 시프트 연산에서 계산 실수 발생 
  → 직접 이진수 재검산으로 오류 발견 및 정정 (0x4F → 0x27)

- BMP280+OLED 통합 후 OLED 미출력, 온도값 고정 출력 증상 발생 
  → HAL 함수 리턴 status 확인 → 브레드보드 세로줄(같은 열)끼리만 통전되는 구조를 
    놓치고 두 디바이스를 다른 열에 배선했던 것이 원인 → 같은 열로 재배선 후 해결

- 변수 선언/사용 이름 불일치, 함수명 오타(white→White, ssd_UpdateScreen→ssd1306_UpdateScreen) 
  → 컴파일 에러로 즉시 발견 및 수정

배운 것
- 데이터시트만 보고 레지스터별 역할(보정계수/설정/측정데이터)을 구분해서 
  전체 통신 흐름을 스스로 설계하는 경험
- Blocking 함수 특성을 활용한 I2C 멀티 슬레이브 순차 통신
- 버퍼오버플로우 방어: 여러 케이스를 계산해서 buffer 크기 결정하는 습관
