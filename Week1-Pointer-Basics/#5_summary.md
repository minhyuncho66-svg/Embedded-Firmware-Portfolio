#5 BMS 센서 구조체 기초

### 오늘 배운 것
- 구조체로 여러 관련 데이터(temperature, humidity, timestamp)를 
  하나로 묶어서 관리 가능
- 구조체 포인터(->)로 함수에 넘기면 
  Day 2의 Call by Reference처럼 원본을 직접 수정 가능
- sizeof(구조체)가 각 멤버 크기 단순 합(2+1+4=7바이트)이 아니라 
  8바이트로 나옴을 직접 확인
  → 이유는 "패딩" 때문, 2주차 Day 8에서 완벽히 배울 예정

### 예측 vs 실제
- Q3: sizeof가 합계와 같을 거라 예측 → 실제로는 다름 (7 vs 8)
  → 왜 다른지는 아직 완벽히 모르지만, 2주차에 이유를 배울 예정

### 오늘 겪은 시행착오
- scanf를 잘못 사용했다가, Day 2의 swap_correct처럼 
  포인터로 직접 값을 대입(pdata->temperature = 25;)하는 게 
  맞다는 걸 깨닫고 수정
- 함수 반환 타입(void)을 빼먹었다가 추가함
